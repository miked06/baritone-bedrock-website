Release notes and all files. The optional BaritoneBedrock.pdb file contains symbols for crash diagnosis. The control panel connects to an already injected DLL; it does not install or inject it.

Requirements and compatibility

  • Windows x64 and the supported Minecraft Bedrock package. This DLL does not run on Android, iOS, Xbox, PlayStation, Nintendo Switch or Minecraft Java.
  • A DLL injector compatible with the game's process. The project is open source and can also be built from source.
  • An existing world or a server that permits automation. Multiplayer rules and server permissions still apply.

How to install the Minecraft Bedrock bot

  1. Check the Minecraft version, then download BaritoneBedrock.dll using the release link above.
  2. Start Minecraft and open your world. If enabled, turn off “Pause game when focus is lost” so the bot can continue when you switch windows.
  3. Use your injector to load the DLL into Minecraft.Windows.exe. Wait for the Baritone loaded message in chat.
  4. Type #help in Minecraft chat. Try #goto 100 64 100 with coordinates in your world. Use #stop to stop activity and #unload to unload the DLL.
  5. Optionally open BaritoneControlPanel.exe for status, navigation, schematic and task controls. All built-in bot messages and help are in English.

What if injection or a command fails?

Do not assume a newer Minecraft package is compatible. Read the version check and log at %LOCALAPPDATA%\BaritoneBedrock\log.txt, consult the troubleshooting guide, and report reproducible failures with the game version and relevant log. Antivirus flags alone do not establish a file's safety; inspect the source and the release origin.

What has been tested?

The release passes 100 offline regression tests, including AddressSanitizer. Native checks cover selected storage, crafting, smelting, schematic, quarry and animal-feeding scenarios. This does not establish complete Survival or multiplayer coverage. See the validation report before relying on an automated process in a valuable world.
