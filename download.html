Requirements and compatibility

  • Windows 10 or 11, x64, with Minecraft Bedrock 26.63, package 1.26.6301.0.
  • A DLL injector compatible with the game's process. The project can also be built from source.
  • An existing world or a server that permits automation. Multiplayer rules and server permissions still apply.

This Windows DLL does not run on Android, iOS, consoles or Minecraft Java. For package 1.26.6005.0 / Bedrock 26.60, use release 1.6.0. Do not mix binaries and game packages.

How to install the Minecraft Bedrock bot

  1. Check your Minecraft package and download BaritoneBedrock.dll from the v1.7.0 links above.
  2. Start Minecraft and open your world. If enabled, turn off “Pause game when focus is lost” so a background bot job can continue.
  3. Use your injector to load the DLL into Minecraft.Windows.exe. Wait for Loaded. Type #help for a list of commands. in chat.
  4. Type #help. Use #goto 100 64 100 with coordinates in your world. #stop stops activity and #unload unloads the DLL.
  5. Optionally open BaritoneControlPanel.exe for status, the map, navigation, schematic tools, workflows and diagnostic export. The panel connects to an injected DLL; it does not inject it.

Why does nothing happen after injection?

Check %LOCALAPPDATA%\BaritoneBedrock\log.txt. A mismatched game version causes the DLL to refuse loading. Version 1.7.0 fixes the immediate unloading seen after Minecraft updated to package 1.26.6301.0; older DLLs still require their matching older game. Once loaded, the bot waits for a command.

Run #doctor for in-game prerequisites, or export #report "C:\exports\baritone-report.zip" for a local diagnostic archive. Inspect logs and paths before sharing. Consult the troubleshooting guide if a supported build still fails.

What has been tested?

139 C++ core tests and 5 Python importer tests pass. The core also passes under AddressSanitizer. Minecraft 26.63 checks cover loading/reinjection, a command typed in game chat, player/inventory inspection, short navigation and reversible server-confirmed inventory transfers.

Native multi-furnace jobs, production/delivery workflows, construction recovery and broader Survival/multiplayer combinations still need gameplay validation. See the feature and validation matrix. Textured in-game ghosts, portable shulker logistics, trading and rail travel are not part of this release.
