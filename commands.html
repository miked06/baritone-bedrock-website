Baritone Bedrock commands

Updated November 1, 2026 · Maintained by miked06

Baritone Bedrock commands start with # in Minecraft chat. They are handled locally by the injected DLL. Start with #help; use #help command for detailed syntax and #stop to stop current activity.

Navigation, mining and building examples

CommandPurpose
#goto 100 64 100Path toward coordinates you choose in your world.
#mine 32 diamondStart a mining process targeting diamonds.
#farm 32Farm supported crops within the configured range.
#schematic load house.mcstructureLoad a schematic preview before construction.
#schematic requirementsCompare estimated materials with inventory.
#schematic buildBuild the current placement.
#whyInspect recent task failures.
#stopStop bot activity.
#unloadUnload the bot.

Register storage and transfer items

#storage add supplies 100 64 100
#storage deposit supplies cobblestone 64
#storage withdraw supplies oak_planks 32

Register an actual supported container at the chosen coordinates. Transfers require empty destination slots, use normal game requests and wait for accepted results. Partial stacks are preserved rather than merged.

Queue a persistent workflow

#task add goto 100 64 100
#task add wait 5
#task add inventory torch 16
#task list
#task resume
#task pause

Relative coordinates are resolved when added. Recovered workflows are paused and tied to the world/dimension. An inventory condition waits for a quantity; it does not craft that item. Failure stops subsequent actions. Crafting and smelting are explicit workstation commands, not checkpointed task kinds.

Workstations and the other 1.5.0 modules

After registering a table and furnace with #storage add, #craft workbench stick 8 requests additional output and #smelt furnace raw_iron iron_ingot 8 coal 1 runs a furnace batch. Ingredients must already be available; smelting needs separate input/fuel stacks and an empty furnace.

The module command reference covers #protect, #trees, #animals, #quarry, #portal, #vehicle, #survival and #export, including preconditions and validation limits. For the complete existing command inventory, see the full command reference.
